# 🌀 Rick and Morty Character Explorer

Welcome to the character explorer for the Rick and Morty multiverse! This project is built with React, Vite, and Redux.

## 🚀 Get Started (Git Bash)

Follow these steps to set up the project locally using **Git Bash**:

### 1. Clone or download the project
If you have Git installed, you can clone the repository:
```bash
git clone <repository-url>
cd App-Rick-Morty
```

### 2. Install Dependencies
Run the following command to install all necessary packages:
```bash
npm install
```

### 3. Run the Development Server
Start the project in development mode:
```bash
npm run dev
```
Once the server is running, open your browser and navigate to `http://localhost:5173`.

## 🛠️ Project Architecture

- **Frontend**: React 18 with Vite
- **State Management**: Redux
- **Routing**: React Router DOM 6
- **Styles**: CSS Modules and Vanilla CSS
- **API**: [The Rick and Morty API](https://rickandmortyapi.com/)

## 📜 Available Scripts

In the project directory, you can run:

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run preview`: Locally previews the production build.
- `npm run lint`: Runs ESLint to check for code quality.

## 🐧 Bash Compatibility Note
This project is fully compatible with **Git Bash**. Avoid using PowerShell or Command Prompt scripts that use backslashes (`\`) or Windows-specific commands like `dir` or `cls`. Use standard POSIX commands (`ls`, `clear`, `rm -rf`, etc.) for all operations.
